This project takes meeting transcripts as an input and outputs a summary of the meeting along with action items, their owners, and deadlines. We used spaCy for pre-processing and named entity recognition, Sentence-BERT for sentence encoding, and built a heterogeneous graph from the sentence, speaker, topic, and entity nodes. We applied the Personalized PageRank algorithm with action verbs or dates as seeds to rank sentences, and we used Maximum Marginal Relevance to retrieve the most relevant sentences. We evaluated our model using the ROUGE, BERTScore, and action-item F1 score.
